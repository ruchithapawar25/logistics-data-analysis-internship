# Logistics Data Analysis Internship

This repository contains the work completed for the Logistics Data Analysis Internship.

## Week 1 – Strategic Planning and Data Exploration

The Week 1 task focuses on planning a data-driven logistics analysis project.

### Objectives

- Define a realistic logistics scenario
- Identify important logistics KPIs
- Research publicly available logistics datasets
- Understand how data science can improve logistics operations
- Create a strategic roadmap for data analysis
- Illustrate the proposed approach using Python

### KPIs

The main KPIs considered are:

1. On-Time Delivery Rate
2. Late Delivery Rate
3. Average Shipping Time
4. Shipment Cost per Order
5. Order Fulfillment Cycle Time

### Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

### Week 1 Deliverables

- Strategic planning report
- Python analysis illustration
- Public dataset research
- Proposed data-analysis roadmap

## Dataset

The project proposes using the DataCo SMART Supply Chain dataset for analysis.

Dataset source:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
